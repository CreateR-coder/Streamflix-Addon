# Streamflix Addon

An experimental, AI-assisted extension for [Streamflix](https://github.com/CreateR-coder/Streamflix/) that enhances media playback and features. Built using Google Gemini.

## Features

- Seamless integration with Streamflix base application
- AI-assisted feature processing

## Quick Start

1. Download and run `Streamflix.exe`.
2. Launch this addon alongside the main executable.
3. Open your browser and navigate to `http://127.0.0.1:5000`.
